# PUSMATIKA — Pusat Konsultasi Matematika

> **"at your service"**  
> Platform web interaktif dan representasi digital resmi untuk Pusat Konsultasi Matematika (PUSMATIKA), mengintegrasikan keunggulan riset dan aplikasi praktis di bidang Matematika, Ilmu Aktuaria, dan Rekayasa Sistem Informasi.

---

## 🏛️ Tiga Pilar Konsultasi Utama
1. **Matematika Murni & Terapan**: Pemodelan matematika tingkat lanjut, optimasi numerik, riset kuantitatif, kalkulus stokastik, dan analisis data kompleks.
2. **Ilmu Aktuaria & Risiko**: Persiapan sertifikasi PAI/SOA, pemodelan kontinjensi hidup, evaluasi risiko aktuaria, valuasi dana pensiun, dan mitigasi keuangan.
3. **Rekayasa Sistem Informasi**: Arsitektur basis data relasional/NoSQL, rekayasa algoritma, integrasi kecerdasan buatan terapan, dan transformasi enterprise digital.

---

## ✨ Fitur Utama
* **Cinematic Brutalist Modern Aesthetics**: Tipografi eksklusif, noise texture, dan tata letak elegan terinspirasi dari high-end architectural editorial.
* **Visi & 6 Misi Strategis**: Animasi pinning horizontal dengan GSAP ScrollTrigger dan indikator progres interaktif.
* **Modul PUSMATIKA**: Stacking card 3D sticky reveal untuk 6 modul komprehensif.
* **Struktur Organisasi Interaktif**: Beralih dinamis antara Hierarchical Tree View dan Profile Team Cards.
* **Sistem Booking Konsultasi**: Modal pemesanan interaktif terintegrasi langsung dengan WhatsApp generator.
* **Ultra-smooth Scrolling**: Didukung oleh Lenis Smooth Scroll dan GSAP ScrollTrigger.
* **Responsif Sepenuhnya**: Dioptimalkan untuk perangkat mobile, tablet, hingga layar desktop ultra-wide.

---

## 🛠️ Tech Stack
* **Framework**: [React 19](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
* **Build Tool**: [Vite](https://vitejs.dev/)
* **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
* **Animation & Motion**: [GSAP (GreenSock)](https://greensock.com/) (ScrollTrigger)
* **Smooth Scroll**: [Lenis](https://lenis.darkroom.engineering/)
* **Linter**: [Oxlint](https://oxc.rs/)

## 🚀 Memulai (Local Development)

### Prasyarat
* Node.js v18+ atau v20+
* npm, pnpm, atau yarn

### Instalasi & Menjalankan
```bash
# Clone repository
git clone https://github.com/RfqiAlan/Pusmatika-Consulting.git
cd Pusmatika-Consulting

# Install dependencies
npm install

# Jalankan dev server
npm run dev
```

### Build Produksi & Linting
```bash
# Type check dan build production bundle
npm run build

# Menjalankan linter
npm run lint

# Preview build lokal
npm run preview
```
